# Safe Level Ups
Shows the real level up box without the game stalling you.

- Turn off *Level-up pop-up notifications* in Settings > Interfaces first, or the game keeps sending its own.
- The plugin opens the game's own interface from the client instead, so nothing waits on the server.
- Same models, fonts, layout and wording. It is the real interface, not a recreation.
- Click anywhere or press space to close it. The click still goes through to whatever you clicked on.
- Stays up briefly first, so a click you had already lined up does not take it away unread.
- Waits for the chatbox to be free, so it never covers a dialogue, an amount prompt or a bank search.
- Every level including 99. The skillcape pop-up that follows a 99 is left to the game.
